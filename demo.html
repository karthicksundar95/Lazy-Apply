🤖 AI Prompt Processor

📝 What This Extension Does

Transform any text using AI! The extension takes your input text, processes it with OpenAI GPT or Google Gemini, and returns intelligent results based on your chosen prompt type.

🎯 Example Use Cases
Input: "The quick brown fox jumps over the lazy dog"
Analyze: This is a pangram containing every letter of the English alphabet. It's commonly used for typing practice and font testing. The sentence demonstrates good rhythm and alliteration with "quick" and "lazy" providing contrasting adjectives.
Input: "Write a function to calculate fibonacci numbers"
Code Generation: ```python def fibonacci(n): if n <= 1: return n return fibonacci(n-1) + fibonacci(n-2) # More efficient version def fibonacci_iterative(n): a, b = 0, 1 for _ in range(n): a, b = b, a + b return a ```
Input: "Machine learning is a subset of artificial intelligence..."
Summarize: Machine learning is an AI subset that enables computers to learn and improve from experience without explicit programming, using algorithms to identify patterns in data.
