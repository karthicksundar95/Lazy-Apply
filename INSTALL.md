# Quick Installation Guide

## 🚀 Install AI Prompt Processor Extension

### Step 1: Download Files
Make sure you have all these files in one folder:
- `manifest.json`
- `popup.html`
- `popup.js`
- `styles.css`
- `icons/icon.svg`

### Step 2: Install in Chrome
1. Open Chrome
2. Go to `chrome://extensions/`
3. Turn ON "Developer mode" (top right toggle)
4. Click "Load unpacked"
5. Select the folder with your extension files
6. ✅ Extension installed!

### Step 3: Get API Keys
**OpenAI:** Visit https://platform.openai.com/api-keys
**Gemini:** Visit https://makersuite.google.com/app/apikey

### Step 4: Configure Extension
1. Click the extension icon in Chrome toolbar
2. Click the ⚙️ settings button
3. Enter your API keys
4. Click "Save Settings"

### Step 5: Start Using!
1. Enter your text
2. Choose prompt type
3. Select AI model
4. Click "Process with AI"

## 🎉 You're Ready!

The extension features:
- ✨ Beautiful glassmorphism UI
- 🤖 OpenAI GPT & Google Gemini support
- ⚙️ Customizable settings
- 📋 One-click copy results
- 🎨 Smooth animations
